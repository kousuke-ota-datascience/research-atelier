# 1. 伝承内容

## 1.1. summary

確認できる主要な伝承内容の全体像を、**後続の分析を原典へ毎回戻らず再検討できる程度の密度**で要約する。

summary は数行の紹介文や辞書的定義で済ませない。少なくとも、読者が本文だけから「この伝承では具体的に何が起きる／何が主張され、どのように展開し、何が結果として残るのか」を再構成できるように書く。

物語・体験談・怪談・流言イベント等、時間的進行を持つ伝承では、原則として以下が追えるようにする。

- 発端: 誰が、どこで、どのような通常状況から始まるか
- 異常の顕在化: 最初に何が通常から外れ、何が問題として認識されるか
- 展開: 異常がどのように継続・反復・拡大・変質するか
- 対応: 登場人物や周囲が何を確認し、避け、試し、相談し、実行するか
- エスカレーション／転換: 危険・不可解さ・因果関係がどのように強まるか
- 終端: 明示的に何が起きて語りが終わるか
- 未解決部分: 何が説明されず、何を推測してはならないか

俗信・ジンクス・命題型噂・制度俗説等、必ずしも時間的進行を持たない伝承では、原則として以下が分かるようにする。

- 対象となる状況・対象・行為
- 成立条件または適用条件
- 中心となる主張・規則・因果説明
- 想定される作用または予測
- 帰結
- 回避・制御・利用方法がある場合はその内容
- どこまでが資料上確認でき、どこからが後代解釈・推測か

単に箇条書きを文章化するのではなく、伝承固有の人物・場所・物・行為・順序・因果主張を残した**高密度なパラフレーズ**とする。ただし、原資料にない心理、因果関係、結末、真相を補って物語を完成させてはならない。

複数の異伝が存在する場合は、特定の分析範囲へ先に固定せず、典拠上確認できる主要形と差異が分かるように記載する。後代に一般化した設定が初期資料に存在しない場合は、その差を明示する。

summary の目的は「短くすること」ではなく、**伝承内容を証拠に忠実なまま圧縮し、D01〜D21の分析根拠を自然言語で保持すること**である。

## 1.2. 詳細展開

伝承内容を段階ごとに記録する。`1.1. summary` が全体像を連続した文章で把握するための節であるのに対し、本節は出来事・論理展開を分解して参照可能にするための節とする。

物語・体験談・怪談・流言イベント等、時間的進行を持つものは**詳細時系列**として記述する。俗信・ジンクス・命題型噂・制度俗説等、時間的進行を必須としないものは、**条件 → 主張／規則 → 想定作用 → 帰結**など、その伝承の論理的展開が分かる順序で記述する。

各段階について、可能なら一次資料の位置（頁、段落、レス番号、記事日付、採録番号等）を付記する。summary に記載した重要な展開が、本節のどの段階・どの典拠で確認できるかを追跡できるようにする。
