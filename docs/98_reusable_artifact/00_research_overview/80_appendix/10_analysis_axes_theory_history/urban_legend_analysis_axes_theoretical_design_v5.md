# 0. 研究目的と分析単位

## 0.1 主研究問い

本研究が直接明らかにしようとするのは、次である。

> **異常・不可解・不確実・偶然・危険・不可視な制度その他の、意味形成を要求する事象に対して、人々のあいだで流通する伝承が、どのような解釈・因果・規則・予測・対処を与え、それをどのように共有可能な世界モデルへ変換しているか。**

ここで「世界モデル」とは、必ずしも精密な因果理論を意味しない。

- 「あれは幽霊だ」という命名・カテゴリー化
- 「会社が意図的に壊れるよう設計している」という原因帰属
- 「20歳まで覚えていると死ぬ」という条件付き予測
- 「逆回りしてはいけない」という禁忌化
- 「このメールを転送しないと不幸になる」という行動規則
- 「血液型によって性格が違う」という類型化

のように、不確実な何かを**理解・予測・行動の対象へ変換する構造**を含む。

Weick, Sutcliffe & Obstfeld (2005) が sensemaking を、状況を言語化して明示的に理解可能なものへ変え、それを行動の足場にする過程として整理したこと、および DiFonzo & Bordia (2004, 2007) が rumor を不確実性・脅威下での shared sensemaking / threat management として扱ったことを理論的背景とする。

## 0.2 伝承エントリ

> **伝承エントリとは、人々が異常・不可解・不確実な何かを理解可能なものへ変換するために共有する、独立して伝達可能な最小の意味形成モデルである。**

1伝承エントリをExcelの1行とする。

登場人物、作用対象、作用、帰結、典拠、個別証言が複数存在しても、それだけでは行を増やさない。意味形成モデルの核が変わる安定異伝のみ、別EntryとしてFamily IDで関連付ける。

Krippendorffのunitizingの原則、すなわち「意味を失わずには分割できないものを一緒に保つ」ことを、本研究のrecording/coding unit設計へ適用する。

# 1. 軸とメタデータを分離する

16軸は、伝承エントリ間で比較する**分析変数**である。

一方、以下はレコード管理のための**メタデータ**であり、16軸には数えない。

| メタデータ | 用途 |
|---|---|
| Entry ID | 1行を一意に識別 |
| Family ID | 同一伝承ファミリの異伝・版を関連付ける |
| Entry type | 物語／命題型噂／俗信・ジンクス／体験モチーフ／流言イベント等 |
| Version scope | 原型、後代型、地域型、媒体型など、今回コードする範囲 |
| 主典拠・Source | コード根拠 |
| Evidence rank | 典拠確度 |
| Coding status | 明示／推定／不明／非該当／競合 |
| Coding memo | 判定根拠、異伝差、保留事項 |

**Entry typeは「物語の特徴」ではなく観察単位の形式なので、分析軸から外す。**

# 2. 16軸の全体構造

16軸は4ブロックに分ける。

| Block | 問い | 軸 |
|---|---|---|
| A. 社会的存在 | この伝承はどう存在し、どう真実らしさを提示するか | 1–3 |
| B. 意味形成 | 何を問題とし、どんな解釈を与えるか | 4–7 |
| C. 因果・行動モデル | 何が、誰に、どう作用し、どう制御できるか | 8–14 |
| D. 社会的埋め込み | 誰が知り、現実世界にどう接続されるか | 15–16 |

最終形は次である。

| # | 軸 | 中心質問 |
|---:|---|---|
| 1 | 来歴・生成変容史 | いつ・どこから生まれ、どう変化したか |
| 2 | 伝達・提示形式 | どの媒体・コミュニケーション形式で伝わるか |
| 3 | 真実性提示・認識論的スタンス | どのような「本当らしさ」で提示されるか |
| 4 | 意味形成対象 | 何が不可解・不確実だから説明が必要なのか |
| 5 | 意味形成契機・手掛かり | 何を証拠・徴候として解釈が開始されるか |
| 6 | 意味付与操作 | その伝承は不可解なものをどう理解可能にするか |
| 7 | 因果源存在論 | 原因・因果主体を何として置くか |
| 8 | 発動・接触条件 | どの条件で因果系が開始するか |
| 9 | 作用対象 | 誰／何に作用するか |
| 10 | 作用機構 | 因果源が対象へ何をするか |
| 11 | 帰結 | 最終的に何が変わるか |
| 12 | 作用時間曲線 | 作用が時間上どう展開するか |
| 13 | 回避・制御可能性 | 回避・停止・利用・検証できるか |
| 14 | 作用レイヤー | 因果効力が物語内・受容者・社会のどこに及ぶか |
| 15 | 情報・認識分布 | 誰が知り、誰が真相を持つか |
| 16 | 現実アンカー | 現実の場所・制度・史実・証拠へどこまで接続するか |

# 3. Axis 1 — 来歴・生成変容史

## 目的

伝承エントリが**社会的対象としていつ・どのように生成され、どのように変形・再流通したか**を記述する。

旧14軸の「来歴」と「伝説生成履歴」を統合する。

## 構成

`生成時期 | 初期媒体 | 主要変容パターン | 現代流通状態`

### 生成時期

戦前／戦後直後／高度成長期／1970s／1980s／1990s／2000s前半／2000s後半／2010s／2020s以降／不明

### 主要変容

- 単発固定
- 口承変異
- 再話・定型化
- 原型→増補
- 媒体移行
- ネット再増幅
- 共同生成
- シリーズ化
- メディアミックス
- 実事件→伝説化
- 再燃・再文脈化
- 検証・反証を伴う再流通
- 起源喪失

## 他軸との境界

「何を媒体として今提示されるか」はAxis 2。Axis 1は**時間的変化**を扱う。

# 5. Axis 3 — 真実性提示・認識論的スタンス

## 目的

伝承が、内容を**どの程度・どの仕方で現実の主張として提示するか**を記述する。

legend研究ではtruth/beliefの扱いが中心問題であり、現代伝説研究も narrative だけでなく rumors, sayings, beliefs を広く扱う。本軸は、怪談作品と「本当にあったらしい」という伝承を区別する上でも重要である。

## 主な値

- E1 直接体験として主張
- E2 身近な伝聞として主張（FOAF等）
- E3 地域・共同体の事実として主張
- E4 一般事実・制度・科学的事実として主張
- E5 条件付き信念として提示（「〜すると〜らしい」）
- E6 真偽未確定として提示
- E7 否定・反証と併存
- E8 虚構起源が既知だが伝承として再流通
- 不明

## 注意

研究者が「真実」と判断する軸ではない。**語り手・伝承がどんな真実性を要求しているか**をコードする。

# 6. Axis 4 — 意味形成対象

## 目的

この研究の中核軸。

> **そもそも何が不可解・不確実・説明を要求するため、この伝承が必要になるのか。**

## 主カテゴリ

- U1 異常な知覚・身体経験
- U2 未知存在・遭遇
- U3 死・喪失・死後
- U4 場所・空間の異常／危険
- U5 事故・災害・反復する不運
- U6 犯罪・対人脅威
- U7 身体・健康・食品リスク
- U8 技術・製品・システムの不可解
- U9 組織・制度の不透明性
- U10 偶然・運・吉凶
- U11 人格・属性・個人差
- U12 社会変動・不足・集団不安
- U13 歴史・場所の記憶／由来
- U14 規範違反・禁忌・道徳的不安
- U15 情報そのものの不確実性／空白
- U16 その他

### 自由記述

カテゴリだけでなく、1文で**対象命題**を書く。

例:

`U9 組織・制度の不透明性 | なぜ製品が保証期間後に壊れるように感じられるのか`

## 複数ラベル

主1、副最大2。

# 7. Axis 5 — 意味形成契機・手掛かり

## 目的

意味形成対象に対し、**何が「これは説明すべき問題だ」と認識させる手掛かりになるか**を記述する。

sensemakingでは、曖昧な状況から何を手掛かりとして抽出・関連付けるかが重要である。rumor研究でも仮説形成、懐疑的検討、証拠提示、追加情報探索が観察される。

## 主な値

- C1 直接経験
- C2 他者証言
- C3 反復・偶然のパターン
- C4 物的痕跡・写真・録音・記録
- C5 実在事件・事故・災害
- C6 地名・建物・歴史的痕跡
- C7 制度上の空白・非公開性
- C8 技術的不具合・異常動作
- C9 統計・疑似統計・経験則
- C10 報道・文書・公式情報の断片
- C11 既存伝承・他の噂
- C12 手掛かりなし／命題先行
- 不明

## 意味形成対象との違い

Axis 4は**何を説明したいか**、Axis 5は**なぜそう考え始めたか**。

# 8. Axis 6 — 意味付与操作

## 目的

不可解な入力を、伝承が**どのような認知・社会的操作によって理解可能にするか**を分類する。

## 主な値

- S1 命名・カテゴリー化
- S2 原因帰属
- S3 意図・主体帰属
- S4 パターン化・相関化
- S5 予測・予兆化
- S6 リスク警告化
- S7 規範・禁忌化
- S8 対処・制御規則化
- S9 吉凶・報いとしての意味付与
- S10 人格・属性類型化
- S11 社会的境界化（内集団／外集団、正常／逸脱）
- S12 隠された制度・陰謀として説明
- S13 歴史化・由来化
- S14 空白・不可知性の保持

主1、副最大2。

## 重要性

Axis 4が「問い」、Axis 6が「答え方」。

例:

- 人面犬: U2未知存在 → S1命名・カテゴリー化
- ソニータイマー: U8製品故障 → S2原因帰属 + S12制度／企業意図
- カーネルの呪い: U5反復する敗北 → S9吉凶化 + S13由来化
- 血液型性格判断: U11個人差 → S10属性類型化 + S4相関化

# 9. Axis 7 — 因果源存在論

## 目的

伝承が、原因・作用主体を**何として世界内へ配置するか**を分類する。

旧「異常源存在論」を、超自然を前提にしない「因果源存在論」へ改称する。

## コード

- N1 人間個人
- N2 人格的超自然存在
- N3 正体不明の外在存在
- N4 生物・未知生物
- N5 物体・人工物
- N6 身体内部の存在／過程
- N7 情報・記号・知識
- N8 場所
- N9 空間・世界
- N10 共同体・家系
- N11 組織・制度
- N12 神格・超越的秩序
- **N13 自然・物理・生物学的属性／過程**
- **N14 現象・体験そのもの**
- 不明

## 理論修正

旧N13「複合」は存在論ではないため廃止する。複合ケースは**主因果源1＋副因果源最大2**で表す。

N14は「異常体験はあるが独立した主体を仮定しない」ケースを扱う。

# 10. Axis 8 — 発動・接触条件

## 目的

伝承が提示する因果モデルにおいて、**何を契機に対象が作用系へ入るか**を示す。

## 主カテゴリ

- 感覚: 見る／聞く／触る／嗅ぐ
- 認知: 知る／読む／理解する／記憶する
- 行動: 呼ぶ／答える／乗る／降りる／入る／開ける／持ち帰る／撮影する／儀式を行う
- 社会: 会う／雇われる／契約する／話を聞く
- 条件: 特定時刻／特定場所／年齢／属性／偶然条件
- 受動経験: 発症する／経験する／巻き込まれる／受信する
- 接触不要
- 不明
- 非該当

## 注意

「読者がその伝承を知ること」と、「伝承世界内で知ることが発動条件であること」を混同しない。

# 16. Axis 14 — 作用レイヤー

## 目的

伝承で主張される因果効力が、**どの現実層に及ぶか**を示す。

## 値

- L1 物語内層
- L2 受容者層
- L3 社会現実層

複数併記可。

### L1 物語内層

語られた世界の登場人物・物体・環境に作用。

### L2 受容者層

話を読む・聞く・受信する者自身が、伝承内容上の因果対象になる。

例: 「この話を聞いた人は3日以内に誰かへ話さないと呪われる」。

### L3 社会現実層

噂の流通・信念・行動によって、伝承外の現実社会に結果が生じる。

例: 買い占め、差別、商品の売上変化、正常ファイル削除、避難行動。

## 注意

L2とL3は異なる。

- 「聞いただけで呪われる」→ L2
- 「噂を信じて買い占める」→ L3

# 17. Axis 15 — 情報・認識分布

## 目的

**誰まで伝承が流通しているか**と、**誰が真相・追加情報を保持するか**を分ける。

## 15A 流通範囲

- 個人
- 家族
- 被害者／経験者集団
- 学校・若者集団
- 地元共同体
- 職業・専門コミュニティ
- 組織内部
- ネット群衆
- 一般社会・広域公開
- 不明

## 15B 特権情報保持者

- なし
- 家族
- 地元内部者
- 専門家
- 組織
- 加害者
- 語り手のみ
- 全員知っているが話さない
- 誰も知らない
- 情報自体が危険
- 不明

## 意味

情報非対称、沈黙、専門家権威、共同体境界等を比較可能にする。

# 18. Axis 16 — 現実アンカー

## 目的

伝承が、その意味形成モデルを**実在世界のどの程度具体的な対象・事実へ固定するか**を測る。

## 尺度

### 0 — 匿名・抽象

特定可能な現実要素へほぼ依存しない。

### 1 — 一般的現実背景

学校、病院、工場、旅行、家庭等。

### 2 — 具体的実在対象

実在地名、施設、路線、企業、商品、人物等。

### 3 — 実在制度・社会史がモデルの成立条件

行政制度、企業制度、軍事史、医療制度、災害史等。

### 4 — 史実・記録・既存伝承を因果構造へ統合

特定の事件・史実・伝承が原因モデルへ組み込まれる。

## 注意

典拠が学術論文であることと、Entryの現実アンカーが高いことは別。

# 22. 理論的な役割分担

16軸は、以下の変換を表現する。

```text
[社会的存在]
来歴 → 伝達形式 → 真実性提示

        ↓

[意味形成]
意味形成対象 → 手掛かり → 意味付与操作 → 因果源

        ↓

[因果・行動モデル]
発動条件 → 作用対象 → 作用機構 → 帰結
                      ↓
               時間曲線・制御可能性
                      ↓
                 作用レイヤー

        ↓

[社会的埋め込み]
情報・認識分布 ↔ 現実アンカー
```

この順序は、必ずしも伝承が実際に生成された心理過程を表すものではない。

**分析上の分解モデル**であり、内容から人間の心理因果を直接推論してはならない。

# 25. コーディングの一般原則

1. **1行を分割しない** — 作用対象が複数でも1Entry。
2. **典拠から分からないものを推測で埋めない** — 不明を使用。
3. **非該当を不明と区別する**。
4. **主コード＋副コード方式**を優先し、無制限multi-labelを避ける。
5. **研究者の事実判断と伝承内の主張を分ける** — とくにAxis 3, 7, 16。
6. **M0は厳格運用** — 作用情報欠落はM0ではない。
7. **FamilyとEntryを区別する** — 安定した意味形成核の差だけ別Entry化。
8. **実証された社会効果と物語内の主張をAxis 14で分ける**。

# 27. 暫定結論

本研究の16軸は、怪異の種類を分類する体系ではない。

> **「何が不可解だったのか」から始まり、その不可解さがどのような手掛かりを通じ、どのような意味・原因・規則・予測・対処へ変換され、そのモデルがどのような真実性と社会的情報構造を伴って流通するかを記述する体系**

として設計する。

これにより、怪談、都市伝説、制度噂、身体俗説、ジンクス、災害流言、異常体験を、単に同じ表へ押し込めるのではなく、**異なる表現形式を持つsense-makingモデルとして比較する**ことが可能になる。
