# 2. change history

## 2.1. No.1 -> No.2

### 2.1.1. 変更の契機

No.1は、都市伝説・怪談等を新規創作するための**14分類軸リファレンス**として設計されていた。来歴、物語内時間、語り形式、異常源存在論、接触様式、異常作用、帰結、被害時間曲線、回避可能性、情報分布、由来説明度、現実アンカー、物語単位、伝説生成履歴を組み合わせて、作品や伝承の構造を表現する発想であった。

この体系をRound8の正規化分析母集団406件へ適用すると、創作用の座標系としては有用でも、実在伝承の比較分析では、**資料不足と構造上の非該当を区別できない、非物語型Entryへ物語用軸を無理に適用する、異常作用M0が過大計上される**という問題が顕在化した。

### 2.1.2. 創作用リファレンスから分析用コードブックへの拡張

No.2では、体系の目的を創作支援だけでなく、既存の都市伝説、噂、怪談、俗信、流言、技術デマ、異常体験ロア等を比較する**分析用コードブック**へ拡張した。

分析対象を「超自然的な物語」に限定せず、命題型噂や制度俗説、災害流言等を同じ比較枠へ入れる必要が明確になった。

### 2.1.3. 分析単位メタデータの導入

同一母集団に、完成した物語、伝説ファミリ、命題型噂、体験モチーフ、流言イベント等が混在していたため、14軸とは別にコード化対象の形式を宣言するメタデータを導入した。

これにより、「値が分からない」と「その分析単位には軸自体が成立しない」を分ける方向へ進んだ。

### 2.1.4. コード状態の導入

値そのものとは別に、以下の状態を導入した。

- 明示
- 推定
- 不明
- 非該当
- 競合

最重要の修正は、**不明をM0で代用しない**ことである。M0は「作用について情報がない」ことではなく、「追加作用を必須としないことが資料から確認できる」場合に限定した。

### 2.1.5. 14軸内部の主な修正

- 物語内時間に `非該当` を導入し、成立・流通年代を主人公の活動年代へ転記しない規則を追加した。
- 語り形式に、単文命題、事実主張、警告、ジンクス、デマ投稿等の**命題・噂提示系**を追加した。
- 異常源存在論に `N14 現象・体験` を追加し、「正体不明の主体」と「独立主体を仮定しない異常体験」を分けた。
- 接触様式に、経験する、発症する、巻き込まれる、受信する等の受動経験を追加した。
- 異常作用に `M24 環境物理作用`、`M25 情報誘導・行動誘発` を追加した。
- 回避可能性に、情報検証、訂正、不拡散等の非超自然型伝承に必要な制御を加えた。
- 情報分布を、**流通範囲**と**特権情報保持者**へ分ける方向を明示した。
- 来歴に、媒体移行、再燃・再文脈化等を追加した。
- 「被害時間曲線」を、正・中立の作用も含められる**作用時間曲線**へ改称した。

### 2.1.6. この版の位置付け

No.2は、14軸という外形は維持しながら、**実データへ適用可能な分析体系へ移行する最初の実証的改訂**である。

## 2.2. No.2 -> No.3

### 2.2.1. 変更の中心

No.2で欠損状態を導入した後も、旧体系で主異常作用 `M0` は278/406件と極端に多かった。この分布を実態と解釈せず、作用の観測単位が不足している可能性を検討した。

その結果、「何が起きるか」だけでなく、**誰／何に作用したか、どの現実層に作用したか**を明示する必要があると判断した。

### 2.2.2. 作用レイヤーの導入

14軸そのものは維持しつつ、作用レイヤーを追加した。

- L1 物語内層
- L2 受容・伝播層
- L3 越境層

これにより、作中人物への作用と、その話を聞いた・読んだ受容者への作用を分けた。

### 2.2.3. 作用対象の導入

主人公、他の登場人物、特定被害者、共同体、組織、物体・設備・環境、世界、読者・聞き手、次の受信者等を区別し、**異常作用の対象**を別に記録する設計へ進んだ。

### 2.2.4. 作用レコード案

作用を可能な限り、

```text
[作用レイヤー] | [作用対象] | [異常源] | [接触様式] | [異常作用] | [帰結] | [作用時間曲線] | [回避可能性]
```

という組として記録する案を導入した。この段階では、同一伝承内の複数作用を複数レコードとして持たせる構想であった。

### 2.2.5. M0付与条件の厳格化

M0を付与する前に、対象バージョン、主人公以外、受容者層、環境・物体への作用まで確認する方針を明示した。一行要約に危害が書かれていないだけではM0としない。

### 2.2.6. この版の位置付け

No.3は、14軸を維持したまま、因果構造の記録を**何が起きるか → 誰に、どの層で、何が起きるか**へ精密化した版である。

## 2.3. No.3 -> No.4

### 2.3.1. 最大の理論転換

No.3までは、基本的に「都市伝説や怪談を構成する特徴を分類する」体系であった。No.4では研究目的を、伝承を通じた **sense-making（意味形成）** の比較へ置き直した。

中心的な研究問いは、概ね次の形となった。

> 異常・不可解・不確実・偶然・危険・不可視な制度その他の、意味形成を要求する事象に対して、人々のあいだで流通する伝承が、どのような解釈・因果・規則・予測・対処を与え、それをどのように共有可能な世界モデルへ変換しているか。

これにより、「怪異の種類を分類する体系」から、**伝承が不可解な対象を理解可能・予測可能・対処可能なものへ変換する構造を比較する体系**へ研究の中心が移った。

sense-making概念そのものの補足は `../20_what_is_sense_making.md` を参照する。

### 2.3.2. 観察単位を伝承エントリとして固定

No.4では、

> 伝承エントリとは、人々が異常・不可解・不確実な何かを理解可能なものへ変換するために共有する、独立して伝達可能な最小の意味形成モデルである。

と定義し、**1伝承エントリ = Excelの1行**を採用した。

人物数、被害者数、作用数、典拠数では行を増やさず、「世界のルール」が安定して変わる場合に別Entryを検討する設計となった。

### 2.3.3. 16軸への再構成

旧14軸をそのまま増築せず、伝承エントリを観察単位として16軸へ再構成した。

特に以下を研究の中核へ導入した。

- 意味形成対象
- 意味形成契機・手掛かり
- 意味付与操作
- 因果源存在論

旧「異常源存在論」は、超自然を前提にしない**因果源存在論**へ変更した。

### 2.3.4. 旧軸の再配置

- 物語内時間 → 物語型Entryだけに必要な補助メタデータ
- 物語単位 → Entry_Type / Family_ID等のunitizingメタデータ
- 伝説生成履歴 → 来歴・生成変容史へ統合
- 由来説明度 → 複数次元から派生可能な説明閉鎖度へ移行

### 2.3.5. 複数作用レコード方式の撤回

No.3で導入した「作用ごとに子レコードを作る」案は、**1行 = 1伝承エントリ**を壊すため撤回した。

作用対象、作用機構、帰結を1行内でmulti-label化し、必要なら対応関係を簡易記法で保持する方針へ変更した。

### 2.3.6. この版の位置付け

No.4は、分析体系の目的と観察単位を同時に再定義した**理論上の転換点**である。

## 2.4. No.4 -> No.5

### 2.4.1. 16という軸数を固定しない

No.4の16軸には、1つの軸の内部に複数の独立した研究質問が含まれていた。No.5では「16軸」という数を守ることをやめ、各分析変数が意味論的にも統計的にもできるだけ独立した情報を持つよう分解した。

その結果、**21分析軸**となった。

### 2.4.2. 主な分解

- 来歴・生成変容史 → 生成年代 / 初期媒体 / 現行・主要流通媒体 / 生成・変容パターン
- 伝達・提示形式 → 提示形式を独立化し、媒体情報を来歴側へ分解
- 帰結 → 帰結極性 / 帰結領域
- 情報・認識分布 → 流通範囲 / 特権情報保持者

sense-makingの中核である意味形成対象・契機・意味付与操作、因果源、発動条件、作用対象、作用機構、回避・制御等も個別次元として保持した。

### 2.4.3. データ型の導入

各軸を以下の型で実装する設計を導入した。

- S: Single nominal
- O: Ordinal
- H1: Hierarchical single
- H3: Hierarchical primary-secondary
- B: Binary vector

階層型では Parent / Child を分類粒度、Primary / Secondary をEntry内の重要度として分離した。

### 2.4.4. Parent / ChildとPrimary / Secondary

- Child → Parent は一意のmany-to-one写像
- ParentはChildから導出する
- Primaryは次元内の中心構造を1つだけ持つ
- SecondaryはPrimaryだけでは失われる独立した追加構造を最大2つ持つ

という原則を採用した。

### 2.4.5. 情報量評価

Shannon entropy、normalized entropy、effective category count、rare code率、U率、NA率、intercoder agreement、次元間冗長性等をパイロット後に確認する方針を導入した。

コード数の多さ自体を情報量や研究価値と同一視しないことも明示した。

## 2.5. No.5 -> No.6

### 2.5.1. 21軸から21概念次元へ

No.5では「分析軸」とExcel物理列の関係がなお曖昧であった。No.6では、**概念次元（theoretical dimension）と保存フィールド（storage field）を明確に分離**した。

21という数はExcel列数ではなく、研究上区別して問う概念的な質問の数である。

### 2.5.2. 三層モデル

以下を分離した。

1. 理論層 — Conceptual Dimensions
2. コーディング層 — Atomic Coding Fields
3. 分析層 — Derived Analysis Fields

Parentはコーダーが独立に判断する値ではなく、Childから導出する粗視化とした。

```text
Parent = f(Child)
H(Parent | Child) = 0
```

### 2.5.3. 「次元」と「列」の区別

H3次元では、Primary Child、Secondary Child、Status、派生Parent等により複数列を使うが、すべて同一の研究質問を表現するなら1概念次元である。

したがって、**21概念次元 ≠ 21 Excel列**である。

### 2.5.4. H3の形式化

H3を、

```text
X_d = (p, S)
p = primary child, exactly 1
S = unordered set of secondary children, 0 <= |S| <= 2
```

として扱い、Secondary 1 / 2を保存位置にすぎない順不同集合として整理した。

### 2.5.5. Dimension Statusの明確化

`D / I / U / NA / C` を各概念次元の判定状態として整理し、Entry全体のworkflow statusと区別した。

## 2.6. No.6 -> 現行正本 v4

### 2.6.1. パイロットによる測定概念の再検討

21概念次元自体は維持したが、パイロット運用によって、特にD02、D03、D16の問い方に修正が必要であることが分かった。

### 2.6.2. D02 / D03の再定義

D02は「初期媒体」から**最古確認流通媒体**へ変更した。

これは伝承の実際の起源を推定する次元ではなく、**現在の証拠によって、実際に人から人へ流通したことを最も古く確認できる媒体**を記録する次元である。

D03は「現行・主要流通媒体」から**確認流通媒体ポートフォリオ（Version Scope）**へ変更した。「現在」「主要」という検証困難な概念を廃止し、今回コードするVersion Scope内で実際に確認できる媒体を記録する。

D02とD03が同じ媒体になることも許容する。

### 2.6.3. D16の再定義

旧「作用時間構造」は、単なる時間曲線ではなく、**発動条件・原因成立から主作用／主帰結までが時間上どのように編成されるか**を測る次元として再整理し、**因果時間構造**へ変更した。

現行では7 Parentの設計を採用し、単一事象内の段階進行を扱う `SEQUENTIAL_EPISODE` 等も区別する。

### 2.6.4. その他の同期

- D01の年代区分を現行9値へ同期した。
- D06を現行7値へ同期した。
- 21概念次元は維持した。
- Parent / Childは理論文書内の「候補」ではなく、`20_urban_legend_parent_child_code_system.md` で定義される現行測定体系として位置付けた。
- Child一覧、Primary選択、include / exclude条件等の詳細は理論設計から分離し、`20`と`30`へ委譲した。

### 2.6.5. 文書責務の分離

現行では、

- `10` = なぜ・何を測るか
- `20` = それをどの値で測るか
- `30` = 証拠からその値をどう判定するか

という責務分離を採用している。

本ディレクトリはこれらと競合する現行仕様を定義せず、**その設計がどのような問題と判断を経て成立したか**を記録する。

### 2.6.6. 現在の到達点

現行モデルは、

> **1伝承エントリ = 1意味形成モデル**

を21概念次元へ分解し、Parentを母集団比較の標準粒度、Childを精密記述、Primaryを次元内の中心構造、Secondaryを独立した追加構造として扱う。

履歴全体は概ね次の流れとして整理できる。

```text
創作のための14分類軸
→ 実データ適用による欠損・非該当・M0問題の発見
→ 作用対象・作用レイヤーの導入
→ sense-makingを中心とした16軸への理論再設計
→ 複合軸を分解した21分析軸
→ 21概念次元と保存フィールドの分離
→ パイロット結果を反映した現行21概念次元 v4
```
