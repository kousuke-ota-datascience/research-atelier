# 1. 目的

本規則は、同じVersion Scopeと証拠を与えられた複数コーダーが、21概念次元について可能な限り同じコードへ到達するための操作規則である。

コード値を埋めること自体を目的にしない。証拠が不足する場合は `U`、構造上適用できない場合は `NA`、同一Scope内で競合する場合は `C` を使用する。

---

# 2. 不変条件

1. **1伝承エントリ = 1行。** 人物・作用・媒体が複数でも行を増やさない。
2. Family内で世界のルールが変わる安定異伝のみ別Entry候補。
3. Parentは入力しない。`Parent=f(Child)` として自動導出する。
4. H3のPrimaryは `D/I` 時に exactly 1。
5. Secondaryは0–2、順不同。保存時のみcode ID順にcanonicalize。
6. `U/NA/C` はコード値ではなくDimension Status。
7. 研究者が真偽を知っていることと、伝承が何を主張するかを分離する。

---

# 3. 証拠ロール

| Evidence role | 用途 | 例 |
|---|---|---|
| `C` Content | 伝承内容、条件、作用、帰結、時間構造 | 原投稿、採録本文、同時代記事による内容引用 |
| `H` History | 成立・流通年代、媒体、変容史 | 同時代報道、媒体史、初出検証、採集史 |
| `X` External effect | 現実社会で実際に起きた効果 | 買い占め、暴力、削除行動、制度対応 |
| `A` Anchor | 実在地・制度・史実との接続 | 公的記録、公式ガイドライン、史料 |

同一資料が複数roleを持ってよい。

**証拠優先順位**


1. 原投稿・同時代一次記録・公式文書
2. 原著論文・民俗採録・同時代報道の再掲
3. 高品質な書誌・研究書・専門家による歴史整理
4. 信頼できる二次資料
5. その他の解説

下位資料しかない場合はStatusを `I` とし、根拠メモを残す。

---

# 4. Dimension Status

- `D` Direct — 典拠に直接明示
- `I` Inferred — 定義と証拠から合理的に推定
- `U` Unknown — 資料不足
- `NA` Not applicable — 構造上非該当
- `C` Conflict — 同一Version Scope内で競合

`U` を「最もありそうな値」で埋めてはならない。

---

# 5. コーディング順序

原則として次の順に行う。

1. Entry_ID / Family_ID / Entry_Type / Version_Scopeを固定
2. D07 意味形成対象
3. D08 意味形成契機
4. D09 意味付与操作
5. D10 因果源存在論
6. D11 発動・接触条件
7. D12 作用対象
8. D13 作用機構
9. D14 帰結極性
10. D15 帰結領域
11. D16 因果時間構造
12. D17 回避・制御
13. D18 作用レイヤー
14. D01–D06 来歴・提示
15. D19–D21 社会的分布・現実アンカー

Macro Categoryや旧14軸コードから新コードを逆算してはならない。

# 6. H1 / H3 共通規則

## 6.1. Primary

その次元について、Entryの意味形成構造を最も強く規定するChild。

## 6.2. Secondary

Primaryだけでは失われる、独立した追加構造。背景・舞台・結果の言い換えはSecondaryにしない。

## 6.3. Parent

Childからコードブック表で一意に導出する。コーダーはParentを判断しない。

---

# 7. D01 — 生成年代

最古確認層と推定起源を混同しない。証拠が「遅くとも1994年」までしか示さない場合、1994年を断定的な生成年にしない。年代レンジへ安全に写像できなければU。

---

# 8. D02 — 最古確認流通媒体

## 8.1. 中心質問

> 現在の証拠で、伝承が実際に人から人へ流通したことを最も古く確認できる媒体は何か。

## 8.2. 最重要規則

- 「古い伝説だから口承」「ネット発祥でないから口コミ」は禁止。
- `Entry_Type=FOAF` はD03の流通推定には使えるが、D02の最古媒体の証拠には単独では不十分。
- 後代の事典・研究書は、掲載されているだけでは最古媒体にしない。

## 8.3. 判定フロー

1. 原投稿・原メール・原手紙・同時代記事が発信媒体か → その媒体をD。
2. 後代資料が「学校で聞いた」「子どもの噂」「口コミ」等を明示するか → 対応するORLをIまたはD。
3. 史料が複数あり最古確認媒体が特定できるか → 最古を採る。
4. それ以外 → U。

## 8.4. 例

- 口裂け女：1978年末の子どもの噂が後代専門家整理で明示 → `D02.ORL.PEER_ORAL` I/D。
- きさらぎ駅：2004年2ch実況 → `D02.WEB.FORUM` D。
- JDBGMGR.EXE：チェーンメール → `D02.EDG.EMAIL` D。
- 水からの伝言：1999年写真集が主張の発信源 → `D02.PRT.BOOK` D。
- 初出不明のFOAFを「友人・仲間内伝承」と推定 → **禁止、U**。

---

# 9. D03 — 確認流通媒体ポートフォリオ（Version Scope）

## 9.1. 中心質問

> 今回コードするVersion Scopeで、伝承が受容者へ流通したことを確認できる媒体は何か。

「現在」「主要」という語は使用しない。

## 9.2. Primary規則

複数媒体がある場合、次の順でPrimaryを決める。

1. Version Scopeの成立に構造的に不可欠な媒体
2. 典拠が主な拡散回路として明示する媒体
3. Version Scope内で最も早く直接確認される媒体

残りをSecondary 0–2とする。

## 9.3. Include

- 子ども同士の口コミ
- FOAFとしての対人流通
- チェーンレター・メール
- 原掲示板・SNS
- 同時代新聞・雑誌が伝承を広く再提示し、流通史の一部になったことが確認できる場合
- 書籍・テレビ等が伝承を実際に再流通させたと資料が示す場合

## 9.4. Exclude

- 研究DBに収録されているだけ
- 現在Google検索で見つかるだけ
- ファクトチェック記事が存在するだけ
- 参考文献として書籍が使われただけ

## 9.5. D02との関係

D03 PrimaryがD02と同じでもよい。これは媒体継続を意味する。媒体移行が確認される場合、D04と併せて解釈する。

---

# 10. D04 — 生成・変容パターン

変容が確認できない場合、資料不足を `単発固定` にしない。変化を示すH証拠がなければU。

---

# 11. D05 — 提示形式

研究者による要約形式ではなく、伝承が受容者へ提示される形式をコードする。原実況、FOAF、命題、警告、俗信規則等。

---

# 12. D06 — 真実性提示

研究者の真偽判定ではなく、伝承が要求する認識論的スタンスをコードする。

---

# 13. D07 — 意味形成対象

必ず「この伝承がなければ何が説明されないまま残るか」を一文で書いてからChildを選ぶ。結果や因果源を対象として誤コードしない。

---

# 14. D08 — 意味形成契機

意味形成を開始させる証拠・徴候・パターンをコードする。発動条件D11と分ける。

---

# 15. D09 — 意味付与操作

伝承が不可解さを理解可能にするために行う認知操作をコードする。例：主体帰属、原因帰属、カテゴリー化、意図帰属、規則化、予兆化。

---

# 16. D10 — 因果源存在論

何が因果源として置かれるか。体験報告の存在と超自然原因の実在を分離する。原因主体を立てない異常体験は現象・体験系Childを使う。

---

# 17. D11 — 発動・接触条件

伝承の因果系へ入る条件。単に「読者がこの話を読む」ことを、伝承内容上の発動条件でない限りコードしない。

---

# 18. D12 — 作用対象

作用される対象。人物が複数いても1行を増やさない。Primaryは意味形成上の中心対象、Secondaryは独立した追加対象。

---

# 19. D13 — 作用機構

「何をするか」をコードし、帰結と分ける。資料不足を顕現・観測にしない。

---

# 20. D14 — 帰結極性

主帰結の正負中立をコード。複数が同等ならMixed。研究者評価ではなく伝承内／伝播現実の結果に基づく。

---

# 21. D15 — 帰結領域

最終的に何が変わるか。作用機構との重複を避ける。Primary 1、Secondary 0–2。

---

# 22. D16 — 因果時間構造

## 22.1. 中心質問

> 発動条件・原因成立から主作用／主帰結までの関係は、時間上どのように編成されているか。

## 22.2. v2の重要変更

非物語型・静的命題をUにしない。時間進行を必要としない関係は `STA` として明示する。

## 22.3. 判定フロー

1. 属性・同一性・対応・制度規則等で、時間順序が意味上不要か → `STA`
2. 一つの連続した出来事の中で完結するか → `EVT`
3. 待ち時間・期限・潜伏が意味上重要か → `DLY`
4. 徐々に悪化・進展するか → `PRG`
5. 一度収束した後に再び起こるか → `REC`
6. 作用関係が切れず持続するか → `CON`
7. A→B→C、世代間など対象を移るか → `TRN`
8. 動的時間構造が重要だが資料が足りない → U

## 22.4. STAの例

- 血液型性格判断：「血液型X ↔ 性格Y」→ `STATIC_ASSOCIATION`
- ひよこ鑑定士高給説：「職業Xは高給」→ `STATIC_ATTRIBUTE`
- 事故物件俗説：「一度他人を住ませれば告知義務が消える」→ `STATIC_RULE`
- 樹海で方位磁針が狂う → `STATIC_ASSOCIATION`

## 22.5. EVTの例

- ベッドの下の男：一晩の出来事 → `SINGLE_EPISODE`
- 臓器を抜かれるFOAF：誘引→昏睡→摘出→覚醒 → `SEQUENTIAL_EPISODE`
- きさらぎ駅：一晩の実況内で段階的に異常が進む → `SEQUENTIAL_EPISODE`

## 22.6. 注意

伝承自体が数十年流通していることはD16ではない。D01/D04の問題である。

---

# 23. D17 — 回避・制御

伝承が提示する制御可能性。資料に対処法がないから「不可避」としない。不可避には明示証拠が必要。

---

# 24. D18 — 作用レイヤー

- L1 伝承内因果層
- L2 受容者層
- L3 社会現実層

L3はX証拠が必要。噂なら社会効果が起きそう、という推測だけでは付与しない。

---

# 25. D19 — 流通範囲

媒体D03と分ける。「どの媒体で」ではなく「どの社会範囲まで」流通しているか。

---

# 26. D20 — 特権情報保持者

噂を知っている人ではなく、真相・追加情報・回避情報を偏って保持する主体。

---

# 27. D21 — 現実アンカー

典拠が実在することと、伝承内容が現実へ接続することを分離する。実在制度・史実が主張成立に必要な場合のみ高得点。

---

# 28. 第2パイロットの検証項目

特にD02/D03/D16について以下を比較する。

- U率
- Parent使用数
- H_norm
- K_eff
- 最大Parent占有率
- D/I比率
- v1→v2で変更されたEntry数

**解釈**


- D02はU率低下を唯一の目標としない。**誤った口承推定を減らすこと**を優先する。
- D03は「現行・主要」を捨てたことでU率が大きく下がるかを見る。
- D16はSTA/EVT導入で、非物語型と単一エピソード型の疑似Uが減るかを見る。
